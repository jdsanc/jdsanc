The header uses DM Serif Display Regular, distributed under the SIL Open Font License in `fonts/OFL.txt`. It is rasterized as a 1600 × 240 PNG and displayed at up to 800 × 120, with a responsive width and meaningful alt text in the profile README. Ordinary text remains native GitHub Markdown for accessibility and small screens.

Light: white surface, #141414 ink, #136F64 teal detail. Dark: GitHub's #0D1117 surface, white ink, #C2F3D9 mint detail. The text and layout match across both modes. There are no remote images or runtime font dependencies.

Rebuild both assets with `python scripts/render_header.py` after installing Pillow. The header is an introductory graphic, not a scientific figure.
